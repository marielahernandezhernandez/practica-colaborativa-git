## Parte 5: Conflicto en README

Git no puede decidir automaticamente que cambio conservar cuando dos ramas modifican la misma linea con textos diferentes.
En cambio cuando las personas modifican lineas diferentes, Git puede combinar los cambios automaticamente.

## Parte 7: Trabajo colaborativo

### ¿Que pasaria si ambos trabajaran directamente sobre main?

Seria  mas dificil controlar los cambios y prodria producirse conflictos o errores al modificar el mismo archivo.

### ¿Que ventaja tiene revisar el Pull Request de otra persona?

Permite revisar los cambios, detectar errores y hacer comentarios antes de integrarlos a main.

### ¿Cuando seria mas dificil trabajar con una carpeta compartida?

Cuando varias personas trabajan al mismo tiempo, porque una persona podria sobreescribir los cambios de otra y seria dificil recuperar 
o identificar las versiones.

### Dos vetanjas y desventajas de usar ramas Pull Requests

Ventajas:
-Permiten trabajar en diferentes partes del proyecto sin modificar directamente main.
-Permite revisar los cambios antes de integrarlos.

Desventajas:
-Requieren mas pasos y conocimientos que trabajar directamente que trabajar sobre una carpeta compartida.
